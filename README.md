# Walaa Sallam Portfolio — GitHub Pages Safe Build

Upload **index.html** and the **assets** folder to the root of your GitHub repository.

This build keeps all CSS and JavaScript inside `index.html`, so GitHub Pages only needs the image assets folder beside it.

Repository structure:

```
/
  index.html
  /assets
    ...images...
```

Do not place `index.html` inside another folder.
